# Controller Companion 轻量版

运行 ControllerCompanion.exe。首次运行显示设置；以后从系统托盘图标打开设置。版本 0.6.0 为待完成桌面验收的候选版本，请参阅验证记录。

要求：Windows 10/11 x64、.NET Framework 4.8、Microsoft Edge WebView2 Evergreen Runtime。程序共享系统 WebView2，不随包携带浏览器。

若提示缺少 WebView2，请从微软官方网站下载 Evergreen Runtime：
https://developer.microsoft.com/microsoft-edge/webview2/#download-section

旧版配置继续保存在 %APPDATA%/ControllerCompanion 中，appearance.json、controllers.json、system.json 沿用。WebView2 的缓存位于其 WebView2 子目录。发布文件夹不含个人配置和桌面截图；截图预览只保留在内存中。

- 单按 L3：呼出或收起单转盘。
- 在设定间隔内按下 L3 + R3：呼出双转盘，默认间隔 300ms。
- 三次短按 R3：循环 Windows 已安装的中、英、日输入语言。
- 未呼出时，左摇杆移动鼠标，右摇杆滚动；默认 A、B 为左右键。
- 转盘呼出后，摇杆选字，功能与按键映射可在设置中修改。
- Escape：收起转盘。

系统设置提供八种语言、跟随系统/浅色/深色、开机启动、关闭行为、后台输入和诊断修复。更新入口验证本地新版本文件夹后重新启动；尚未配置在线更新源。固件入口仅打开相应厂商的官方支持页面。

未来界面重绘可修改 web/src/settings.js、settings.css 和 settings.html；转盘 assets/exact、figma-layout.js、wheel-view.js、wheel.css 保留即可。
