# Conroller Plus — Windows 新版规格

日期：2026-09-21

状态：用户已逐项确认全部功能，并在本轮明确图标图片化、220ms 弹簧切换、R3 手势优先级与托盘配色。进入实现计划阶段。

本次交付：Windows 10/11 x64 本地便携版，供用户验收。名称按用户原文使用 **Conroller Plus**。暂不推送、发布或改动 GitHub 上的发布版本。

## 1. 来源与实现方向

- 基础仓库：https://github.com/NorthAngel/project-maties ，已克隆到本地，并建立 `codex/conroller-plus` 分支。
- 主要界面：https://www.figma.com/design/IfZlSFiA71x5b8nRJ70tJG/controller-companion?node-id=299-14
- 实际界面、字体、图标、文字位置、颜色、动画与用户在本次对话中的修正是依据。旧版行为以及上一轮自动整理的图层名称均不能覆盖用户决定。
- 继续使用现有 .NET Framework 4.8 / WebView2 Windows 宿主与 SDL/XInput 手柄读取能力；重做设置界面，并修改输入状态、配置、窗口定位、更新和修复部分。
- 对比方案：重写成纯 WPF 会增加原型材质及动画复现工作；恢复 Electron 会重复已有桌面能力并增加包体。采用现有 Windows 宿主，把变化集中到用户要求的行为和界面。
- Figma 当前 `software` 页：未接入 `321:247`、已接入 `411:110`、控制器设置 `407:107`、语言面板 `355:2`、双盘预览 `354:7`、手柄型号组 `412:135`。

## 2. 窗口与启动

- 设置窗口使用 Figma 中的实际窗口边框尺寸，固定大小，不支持手动调整或最大化；删除预留的最大化按钮。不要用组外散落图层的外接尺寸作为窗口尺寸。
- 整个软件的非交互空白区域可拖动窗口。按钮、滑块、菜单、选项等正常响应自身操作，不触发拖动。
- 标题栏保留最小化与关闭按钮。
- 软件运行并连接手柄后立即允许手柄控制，无须点击 Get started 才启用。
- Get started 隐藏主窗口，仅在系统托盘保留图标，后台输入继续运行。
- 关闭行为仅有“隐藏到系统托盘”和“退出主程序”，默认前者。
- 标题栏最小化、Get started 和关闭到托盘均不得意外停止后台手柄输入。
- 手动启动时打开设置；开机启动默认关闭。用户开启后，登录 Windows 自动后台托盘运行。
- 托盘单击打开设置；右键提供打开设置和退出。退出时停止服务并释放所有模拟按键。
- 托盘图形使用 Figma 基础部件中的 logo；已连接使用当前主题强调色，未连接使用 #BCBDC4。

## 3. 连接状态与设备

- 识别 Xbox、PlayStation、Nintendo Switch 和其他手柄类型。
- 型号显示、按键图标及说明同步适配设备；保持当前 Xbox 原型的字号、线条、尺寸、间距和统一颜色，不能按品牌引入突然的彩色或字号差异。
- 多设备时，在现有型号识别组件上提供设备选择入口；菜单沿用语言面板样式。
- 默认使用最先连接的设备；记住用户选定设备。切换设备前清理旧设备的按住状态和转盘会话。
- 当前控制设备断开：停止其输入，释放键鼠按住状态，收起转盘，自动显示设置主窗口并呈现“手柄未接入”。不另开确认弹窗。
- 重连保留设置。多设备情况下不突然把输入控制权转交另一设备，用户从已有选择入口选择。
- 每个可稳定识别的设备独立保存三套按键映射和左右摇杆死区；外观、窗口、语言等共用。
- 无序列号且相同型号的设备不能虚构可永久区分的身份；身份信息以实际后端提供的数据为准。

### 未接入状态

禁用转盘外观参数、模式等组件设置更改和自定义按键绑定。语言选择、窗口拖动、最小化、关闭、Update、Repair、托盘退出可用。

Get started 是收进托盘的窗口操作，不是启用输入的开关；未连接时也可通过窗口/托盘控制隐藏或退出。

## 4. 三种输入状态及不可修改项

Single / Dual 在设置中选择，默认 Single。L3 在所有状态下固定为呼出/收起当前选定模式，不允许改绑。删除旧 L3+R3 呼出双盘的手势。

只有 L3 与对应状态的选字逻辑锁定；其余功能按键可自定义。

| 状态 | 左摇杆 | 右摇杆 | 方向键默认 | 面部按键默认 |
| --- | --- | --- | --- | --- |
| 收起 | 鼠标移动 | 四向滚动 | 键盘 ↑ ↓ ← → | A 鼠标左键；B 鼠标右键；X/Y 不分配 |
| 单盘 | 选择单盘扇区 | 鼠标移动 | ↑ 空格；↓ 回车；← 上一字符布局；→ 下一字符布局 | 上/左/右/下物理位置对应扇区上/左/右/下字符，锁定 |
| 双盘 | 左盘选区 | 右盘选区 | ↑/←/→/↓ 输入左盘上/左/右/下字符，锁定 | 上/左/右/下物理位置输入右盘相应字符，锁定 |

Xbox 上方 Y、左侧 X、右侧 B、下方 A。PS 和 NS 按物理位置对应其符号，不按跨平台字母名字硬套。

除上述默认绑定及固定 R3 三次短按手势外，LB/RB/LT/RT/R3/View/Menu 等额外按键默认不分配。

### 独立映射

- Collapse Dial / Single-Key Input / Dual-Key Input 各自保存一套配置，运行状态自动使用对应配置。
- 修改任何可绑定按键后，控制器功能键说明中的对应位置立即显示绑定功能名。
- Restore Defaults 仅恢复当前选中状态的按键配置。
- 锁定的选字项与 L3 显示其作用，禁止修改；后端也校验，不能仅禁用前端控件。
- 左右转盘字符布局切换分别提供独立可绑定动作。单盘提供正向/反向字符布局切换。
- 自定义动作支持键盘按键、修饰键及组合快捷操作、鼠标按键、字符布局切换、Windows 输入法切换等本次功能；不重新引入辅助按键层。
- 列表只显示该状态适用动作；用户要绑定的普通按键功能不受“原型只展示几项”的限制。

## 5. 选字、长按、输入法

- 左右摇杆死区独立：默认各 10%，范围 0%–40%。死区为径向判断。
- 转盘初次打开时无选中扇区。摇杆进入死区立即清空选区，选字按键不输出字符；双盘分别判断。
- 上方缺口不对应字符区，不允许沿用上一扇区误输入。
- 字符键、退格、空格、回车、键盘方向键：首次立即触发，按住 400ms 后以 60ms 间隔连续触发。
- 进入死区、释放按键、关闭转盘、切换设备或目标变化导致失去输入会话时，停止字符连发。
- 切换布局、呼出/收起与输入法切换等状态动作每次按下只触发一次，不参与长按重复。
- 鼠标按钮及 Ctrl/Shift/Alt 等修饰键使用按下/松开生命周期，确保拖拽和组合操作有效，不能当成连续点击处理。
- 输入法切换可以绑定给普通可编辑按键。
- R3 三次短按切换输入法继续保留，识别窗口 600ms。三连按成功只切换输入法；普通 R3 短按在排除三连按后执行，其普通绑定允许最多约 600ms 延迟。
- 界面语言和 Windows 输入法相互独立，界面语言切换不强制替换当前输入法。

## 6. 字符布局与动画

- abc / ABC / 123 的字符内容、符号顺序、扇区和位置全部按 Figma 提取。
- 默认字符布局均为 abc。Left disc / Right disc 设置每次呼出时左右盘的初始布局。
- 正向 abc → ABC → 123 → abc，反向 abc → 123 → ABC → abc。
- 单盘左方向键默认反向，右方向键默认正向；双盘左右切换动作绑定到用户自选按键。
- 预览与桌面转盘使用同一份布局及动画数据，避免两套实现不一致。
- 原型的点击/悬浮触发是展示交互，实际软件将其映射到手柄状态；不因此给桌面转盘增加鼠标交互。
- 用户最新指示覆盖旧时长：三个材质的字符布局切换统一为 **220ms 弹簧效果**。使用原型弹簧 mass=1、stiffness=220、damping=24 描述曲线形状，在 220ms 内完成并落到目标状态。
- frosted 的扇区高亮过渡为 150ms、按字反馈 80ms、离开恢复 100ms；具体形状及效果从源节点读取。
- medium/opaque 原记录的异常长时值不能进入软件；字符布局切换以用户最新 220ms 要求为准，交互反馈短时过渡在正常毫秒尺度复现。素材、形状和状态差异继续参考 Figma。

## 7. 外观与预览

| 选项 | 默认/范围 | 行为 |
| --- | --- | --- |
| 模式 | Single | 决定实际呼出单盘或双盘 |
| 字符布局 | 单盘及左右盘 abc | 每次打开读取默认布局 |
| 材质/透明度 | Opaque，滑块 50% | 连续调节；并非把 0% 当成完全不可见 |
| Size | 100%，50%–150% | 以 Figma 转盘尺寸为 100%，实际与预览同比例缩放 |
| 主题 | 跟随系统 | 左浅色/中系统/右深色三档 |
| 鼠标速度 | 5500，150–8000 | 摇杆指针移动速度，不修改实体鼠标硬件 DPI |
| 滚动速度 | 10，1–20 | 四向滚动速度 |

- Frosted / Opaque / Solid 三个设置预设分别对应 frosted / medium / opaque 页面，以及滑块 0% / 50% / 100%。
- 点选预设同步更新实际转盘与滑块，之后可继续连续微调；材质视觉端点按原型读取。
- 外观预览使用 Figma 固定背景；彻底取消桌面截图预览功能和其入口/权限/调用链。
- 预览区域固定，超过边界的转盘裁切，不自动缩小以塞回区域。双盘按原型布局。
- 预览显示手柄实时选区、按键反馈、字符切换与动画。
- 弹出选项面板、下拉菜单、手柄选择、语言选择、更新/修复扩展面板等统一继承“语言选择 / 英文”的圆角、间距、按钮和状态样式。

### 配色

- 浅色强调色 #F77E2D，深色强调色 #394F3E。
- 深色转盘底色向 #484848 靠近，维持材质和透明度；字符反色成为清晰浅色。
- 深色设置窗口 #1E1E1E，面板 #292929，主文字 #F2F2F2，次文字 #B8B8B8，分隔线 #3A3A3A。
- 主题轨道左侧浅色 #D9D9D9；初始系统态参考 #BCBDC4；右侧深色 #394F3E，不能继续保留橙色。
- 未接入状态依据 Figma 禁用态呈现，不允许只改颜色却仍能更改设置。

### 字体

- 文字继续使用内置原型字体，不使用 Segoe UI 或通用系统字体替代。拉丁文字使用 SF Pro；中文使用苹果苹方体系，日文使用苹果 Hiragino 体系。
- 用户最新授权：**全部符号图标与相关按钮图标从 Figma 原节点导出成图片素材**，不只处理本机缺失的 6 个字符。优先原始 SVG 图形，原图形为位图时保留其原始图像。
- 图标作为图片显示，不依赖 SF Symbols 特殊码位。不得手绘、换用其他图标库，或把可翻译的按钮文字烘焙进整张界面截图。
- SF Pro 的普通字形、PingFang SC 和 Hiragino Kaku Gothic ProN 可从本机已存在文件获取。图标缺字不再阻塞。
- 字体资源与应用资源一起固定加载，不要求最终用户手动安装字体。

## 8. 实际转盘窗口

- 转盘不能用鼠标点字，不能手动拖动；鼠标穿透、不激活、不抢走文本编辑焦点。
- 呼出时取鼠标光标位置：单盘顶部缺口中心对齐光标；双盘两个缺口中心连线的中点对齐光标。
- 优先向下展开，盘体不能遮挡正在打字的位置。
- 获取可用的文字光标/输入区域用于避让，结合当前显示器工作区与 Windows 缩放计算位置。
- 边缘空间不足时整体平移或改到上方/侧边，尽量保持完整盘体且避开输入区域。不能通过裁切桌面转盘来处理边缘。
- 转盘打开后位置固定；右摇杆移动鼠标不带动转盘。下一次呼出重新定位。
- 对无法提供文字光标位置的应用，仍以已确认的鼠标锚点作定位，不虚构能读取该应用光标。
- 极端情况（例如双盘 150% 的整体尺寸超过显示器工作区）必须在实现测量后说明可行行为，不能同时声称保持尺寸与完全可见。

## 9. 语言、保存与新版初始化

- 仅支持简体中文、English、日本語。
- 首次默认跟随 Windows 显示语言；不支持的语言回退 English。
- 用户选择保存在现有类型的本地设置文件，不增加语言专用注册表项或后台服务。
- 新版首次运行采用本规格默认值，不迁移旧版设置。
- 新版使用独立配置版本/目录，避免把“重新初始化”做成每次升级或每次启动都清空；后续正常更新保留新版用户设置。
- 新配置读写容错、原子保存；不把个人配置放入构建包、日志或仓库。

## 10. 更新

- 从 NorthAngel/project-maties 的 GitHub Releases 读取最新正式版本；忽略预发布版本。
- 每月后台自动检查一次；如果软件未运行，到下次运行时补做已到期检查，无需为检查单独建立常驻服务。
- 检查只是读取版本信息，不自动下载安装包。
- 有新版时，在更新按钮右侧显示绿色小圆点。
- 用户点击更新后才下载；展示下载与失败状态。
- 下载并验证后提示“更新已下载，立即重启安装”。只有用户确认才退出、替换并重启。
- 替换失败保留/恢复原版；不删除用户设置。程序重启前释放所有输入。
- 月度检查时间及待更新状态保存在本地设置中；断网失败不弹出反复打扰用户的窗口。
- 本次只实现能力和本地验收，不发布一个真实新版来制造更新测试结果。

## 11. Repair

- 检查正常运行所需依赖：.NET Framework、共享 WebView2、原生输入后端及其必需文件。
- 按发布完整性清单检查程序文件缺失/损坏，不能只检查三个原生文件。
- 显示具体问题。用户确认修复后，自动下载所有对应的缺失/损坏组件并修复；不要求用户再逐个勾选。
- 系统依赖使用官方来源；软件文件使用对应版本的受验证发布包，不能随意将修复变成跨版本升级。
- 修复前停止可能占用文件的输入组件；完成后恢复正常运行。
- 需要系统安装权限时走 Windows 正常权限流程，不绕过权限。
- 最小的启动诊断不能完全依赖损坏的设置网页或缺失的 WebView2 才能显示；保留原生启动故障说明/修复入口。

## 12. 删除旧版功能

从新版界面、运行路径和发布包中删除旧校准向导、辅助绑定层、自定义填色/描边入口、厂商固件入口和桌面截图预览。移除已不参与产品的旧 Electron 壳与相关发布路径时，先确认没有新宿主依赖。

原始第三方许可、必要的 SDL 手柄数据库与后端设备映射不能当作“校准界面”一并误删。

## 14. 检查结果及用户最终裁定

### A. 字体缺失

本机 `C:\Windows\Fonts\sf-pro.ttf` 能提供部分 ABXY/方向键图标，但缺少原型中的以下码位：U+100F89、U+100F88、U+101DF7、U+101DF9、U+101E07、U+101E09，涉及部分手柄型号、View/Menu/L3/R3 图形。检查过已安装的 SF Pro Rounded 文件，也不能补齐这六项。

用户裁定：从 Figma 导出图片，覆盖全部符号和按钮图标。完整扫描 software 页发现 22 类唯一符号、13 个带图片填充的图层和 3 处 logo，其中包含重复预览素材，实施时去重并保留源节点记录。已读到缺失图标 L3 的真实 SVG 轮廓；不能用空白方框或重新绘制图案代替。

### B. 原型局部动画时长

主字符切换三页一致为 0.62 秒，但 medium/opaque 中部分反馈过渡由 API 读到 180/220/240/260，按 API 时长单位将变成几分钟；与主切换不一致。

用户裁定：切换动画固定 **220ms 弹簧效果**，覆盖原 620ms 切换和异常时长。
