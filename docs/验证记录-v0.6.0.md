# v0.6.0 验证记录

此版本将原 Electron 桌面壳迁移为 .NET Framework 4.8 + 共享 WebView2，属于待完成桌面验收的候选版本。

## 已完成的自动检查

- 宿主 Release 编译，零警告、零错误。
- 宿主来源限制、系统配置兼容、多显示器与缩放边界检查。
- 原生服务和维护文件的完整性、回滚、服务启停检查。
- JavaScript 输入逻辑及迁移引擎测试：以本次实际测试记录为准。

## 待完成

本次执行环境的命令进程位于 Windows Session 0，桌面位于 Session 1。透明合成验证在前者返回拒绝访问，普通 WebView2 对照验证也返回窗口句柄无效。桌面工具启动时出现 runner pipe 连接超时，因此尚不能认定共享 WebView2 版本已经完成实际桌面验证。

必须在普通用户桌面完成：透明度和原转盘外观、鼠标穿透、焦点保持、手柄文字输入与中英日输入法、双盘、隐藏设置后持续输入、校准、托盘、单实例、截图、开机启动、关闭行为和修复后恢复输入。

v5.5 的实际输入验证不能替代 v0.6.0 的宿主迁移验证。暂时保留 v5.5 作为已验证的可用版本。
