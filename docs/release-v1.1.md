# Conroller Plus v1.1 — Windows 公开预览版

## 下载与运行

下载下方附件 **ConrollerPlus-v1.1-win-x64.zip**，完整解压后运行 `ConrollerPlus.exe`。不要单独移动 exe 文件。

- 平台：Windows 10 / 11，x64。
- 依赖：.NET Framework 4.8、Microsoft Edge WebView2 Runtime（共享运行环境不包含在压缩包内）。
- 校验：附件 `SHA256SUMS.txt` 提供压缩包的 SHA-256。
- GitHub 自动生成的 Source code 压缩包是源码，不能直接作为软件运行。

## 新版功能

- 根据 Figma 原型重做设置界面，支持简体中文、英文、日文。
- 手柄识别与多手柄选择、单盘／双盘输入、鼠标和四向滚动。
- L3 呼出／收起转盘，固定选字逻辑之外的按键可自定义。
- 转盘透明度与尺寸、深浅色主题、独立左右摇杆死区和速度设置。
- 开始使用后隐藏至系统托盘；断开选中的手柄时显示设置窗口，重连保留配置。
- 配置保存在 `%APPDATA%\ConrollerPlus`，首次运行不迁移旧版本配置。

## v1.1 修正

- 修正图标重复平铺、裁切及语言按钮常态颜色。
- 恢复 Figma 的透明度两端图标、轨道与玻璃滑块参数。
- 修正转盘字符颜色，补充 Frosted 预览模糊效果。
- 增加软件窗口圆角，重做支持深浅色的托盘右键菜单。

## 当前限制

这是预览版：自动更新后的替换、回滚与完整依赖修复仍未完成，对应入口会提示；Figma Glass 的光学折射为近似实现，尚未完全一致。
真实手柄跨型号兼容性、不同应用中的输入行为和混合 DPI 多显示器表现仍需实机验收。
