# Conroller Plus v1.1 本地预览版

将压缩包完整解压到一个固定文件夹，打开 ConrollerPlus.exe。不要单独移动 exe 文件。

## 使用

- 插入手柄后自动识别；多个手柄可在控制器选择中切换。
- 点击“开始使用”隐藏到右下角系统托盘；单击托盘图标重新打开设置，右键可完全退出。
- L3 呼出/收起转盘。单盘与双盘、字符样式、透明度、尺寸、摇杆死区和按键功能在设置中调整。
- 未接入手柄时，外观和按键设置不可修改，语言和窗口操作仍可用。
- 默认不开机启动；设置保存在当前用户 AppData/Roaming/ConrollerPlus。

## 这版的边界

这是一份可运行的本地验收预览，不是功能全部完成的正式版。
更新下载后的自动替换、回滚与完整依赖修复尚未完成，对应按钮会说明暂不可用。
界面布局仍需与 Figma 做最后一轮细节验收。真实手柄跨型号兼容性与不同应用中的输入行为尚待实机验收。
程序使用系统的 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.8；压缩包不附带这些共享运行环境。
公开版本与下载位于 https://github.com/NorthAngel/project-maties/releases/tag/v1.1 。

## v1.1 界面修正

修正图标遮罩重复、语言按钮常态/选中态、透明度两端原始图标和 46×30 玻璃滑块；字符恢复黑色 65%（深色反色）。主窗口圆角，托盘菜单使用独立的圆角菜单、图标、分隔线、悬停反馈和深浅色背景。
Frosted 按原始填充和玻璃模糊参数修正。Figma 的折射着色器不能直接由 SVG 导出，当前使用路径内的模糊、透明填充和描边近似，尚不宣称与 Figma Glass 完全一致。
